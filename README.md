## 策略共同架构（逐行核对五版本代码后的准确口径）

日线指标（信令层，当日值）+ 执行层前一日值（全部 `shift(1)`，T-1 口径、无未来数据）
+ 分钟逐 bar 混合回测循环。

**公共前提（v33 成稿，v56 定型后不再改动）**
- 部分日线指标参与决策前统一取 T-1（`daily_exec_bar_df.add_prefix("daily_")` 后按分钟 bar 逐 bar 读取）；
- 日内开仓要求 `intraday_bar_index >= 30`（开盘前 30 根分钟 bar 内不入场）；
- **单日只允许一次建仓**：当日首次成功开仓（含移仓换月接回、反手）后
  `open_memory[cur_trading_date]=True`，当日不再尝试新开仓；
- 合约：指标用 `{PRODUCT}JQ00` 加权指数；实际成交用主力合约数据
  （`_get_major_contract_symbol_and_bar` 取当日主力、`_get_next_major_contract_data`
  取下一主力——临期自动跳过次主力；v33 时代反手直接用当前主力，v56 起统一）。

**开仓路径 A：箱体压缩突破（channel_condition）——v33 定稿骨架**

做多须同时满足（做空逐项镜像）：
1. 通道压缩：`is_channel_compression`（20 日通道宽度 / 20 日波幅通道，
   ≤ 其 60 日 30 分位——"当前通道宽度处于近 60 日最扁的 30% 区间"）；
2. 突破确认：`cur_close > 20 日通道高点 + 0.1×当日 ATR14`；
3. EMA 排列资格：`ema5 > ema10 > ema20` 且 `ema_long_bull_days >= 3`
   （连续排列片段内累计 ≥3 天，翻面重新计数）；
4. 当日方向一致：`cur_return_today_open > 0`（收盘价高于当日开盘）。

**两道公共过滤（v33→v56 之间引入、v56 定型，此后所有版本沿用）**
- SAR 同向门：`daily_sar_trend == ∓1`——T-1 收盘后的 Parabolic SAR 趋势状态与方向一致才可开仓；
- 追高/追跌过滤：当前分钟收盘价与 60 日极值（T-1 口径）的距离超过 50% 涨跌幅即放弃
  （`max_extreme_distance_pct = 0.5`）。

**止损与止盈（路径 A 口径全主线不变）**
- 初始止损：`max(20 日通道低点, 入场价 − 2×ATR14)`（做空：`min(通道高点, 入场价 + 2×ATR)`）；
- **初始止盈价** = `入场价 ± 3×ATR14`：仅作为仓位元数据记录并随移仓换月继承，
  **不直接触发平仓**（出场实际由止损线与动态止盈止损线驱动）；
- 动态止盈止损（跨日生效）：持仓进入非开仓日后，
  做多 `adjust_stop = max(初始止损, 持仓后日内最高价 × 0.8)`，
  做空 `min(初始止损, 持仓后日内最低价 × 1.2)`；盘中收盘价回穿该线即平仓。

**平仓体系（优先级自上而下，v33 成稿、主线五个版本一致）**

多头平仓检查（空头镜像，方向相反）：
1. 反向开仓：达到对面路径 A 开仓条件 → 平仓后立即反手（反手单沿用通道口径止损与 3×ATR 止盈）；
2. 止损：收盘价触初始止损；
3. 动态止盈止损：跨日后回穿调整止损线；
4. 开盘跳空反转：当日开盘相对前日高低点跳空幅度 >1%（收盘价口径）；
5. 真跳空反转：前一日形成"全天无回补缺口"（幅度 >0.5%）且当日盘中 ≥30 根 bar 后收盘价反向；
6. 前一根巨型 K 线：前一日 K 线幅度 ≥ 60 日幅度 90 分位、实体占比 ≥0.8、方向与持仓相反；
7. TRIX 反转平仓：`trix_hist` 回落且 <0（多头）+ 持仓 ≥7 个交易日 + 当前非通道压缩 + `trix_neg_days ≥ 5`；
8. 最后可交易日（回测末根强平）；9. 移仓换月（原止损/止盈继承并换至次主力）。

**指标工具层**：TRIX/TRIX-SIGNAL、MACD、CCL（仓差方向四象限 `ccl_type`）、
Parabolic SAR、EMA5/10/20/40/60、20 日通道与压缩度、7 日短通道、60 日极值窗、
60 日 K 线幅度 90 分位、TR/ATR14/波幅通道。其中 `ccl_type` 在 v72 的路径 B
条件中首次被消费（v81 起又不再消费，仅保留计算）。

# 主线版本详细描述

# trix_vpt_research_v33 —— 单路径骨架定稿

## v33 实际形态（按代码核对）

- **只有路径 A**：通道压缩 + 突破（通道高低点 ± 0.1×ATR）+ 排列 ≥3 天 + 当日方向一致
  + 日内 ≥30 bar；**没有 SAR 同向门、没有 60 日极值过滤**（这两道是 v33→v56 之间
  中间代引入、v56 定型的）；
- 无持仓/有持仓的检查框架、平仓九条优先级、动态止盈止损（×0.8 / ×1.2）、
  移仓继承、最后可交易日强平——全部在本版成稿；
- 反手开仓直接用**当前**主力合约（无临期规避）——此瑕疵在 v56 修复；
- 开仓止损 = `max(通道低点, 入场价 − 2×ATR)`、止盈记录 3×ATR。

## 结论

相对其前代（原记录：调整前一日跳空阈值，现行口径为开盘跳空 1%、真跳空 0.5%）
略微提高收益，且回撤影响不大。**通道压缩骨架与平仓体系自此停止大改**，
后续主线全部围绕"第二条路径"展开。

# trix_vpt_research_v56 —— 双路径完整形态、结构性加固定稿

v56 是本次主线里"骨架之上的两条开仓路径全部到位"的版本，也是此后所有迭代的对照基线。

## v33 → v56 相比主线前作的三个变化

1. **公共过滤到位**：SAR 同向门 + 60 日极值追高过滤（0.5）进入两路径条件
   （见"共同架构"两道公共过滤）；
2. **路径 B（ema_condition）全量启用**：`EmaPackCrossStateMachine`——
   三线（EMA5/10/20）首次全部穿越 EMA40：做多 = 对侧"全下"片段曾持续 ≥30 天、
   今日首次"全上"（做空镜像）。状态机逐日推进（T-1 口径），对侧片段内允许混合日拉锯
   （`max_mixed_gap_days = None` 不设上限）。叠加 SAR 同向 + 极值过滤 + 日内 ≥30 bar。
   路径 B 止损 = **入场价 ± 2×ATR14**（与路径 A 的"通道/2ATR 取大"不同）；
3. **反手开仓合约统一**：平仓反手由"当前主力合约"改为 `_get_next_major_contract_data`
   （临期 <30 天自动跳次主力），多头/空头两条链都改；同时修复"ALL 与单方向运行
   可能开在不同合约"的一致性隐患。

## 验证（FG 对比 v56 前作）

FG ALL：52.64% / -20.90% / 13 笔 —— 与前作完全一致（FG 历史上从未触发反手路径，
修复是纯结构加固）。

# trix_vpt_research_v72 —— 恢复反转搏击 + 两道实证改进

v68→v72 恢复路径 B（触发方式与 v56 完全一致：三线首穿 EMA40 + SAR 同向 +
极值过滤 + 日内 ≥30 bar），加两道数据验证过的改进：

## 改进 1：CCL 方向一致性门

针对 v56 反单路径 21 笔逐笔分析：盈利单 8/9 在信号日（T-1）`ccl_type` 极性与注单
方向**一致**；亏损单 12 笔中 5 笔信号日方向相反（首穿日无任何价格确认 = 回踩噪声首穿）。

落实（`ccl_type` 是仓差方向四象限：价涨/跌 × 增仓/减仓）：
- 做空（breakdown）：`ccl_type ∈ {SHORT_OPEN, LONG_CLOSE}`（价跌+新空头 / 价跌+多头出逃）
- 做多（breakup）：`ccl_type ∈ {LONG_OPEN, SHORT_CLOSE}`（价涨+新多头 / 价涨+空头回补）
（同时验证过：放量门为负贡献——放量反转单更易亏损，弃用）

## 改进 2：反转搏击单的结构位止损

路径 B 止损从"入场价 ± 2ATR"改为**结构位止损**（现行公式）：
做多 = 近 7 日低点 − 1×price_tick；做空 = 近 7 日高点 + 1×price_tick
（7 日通道对侧沿，收盘价穿回结构位 = 反转失败即离场）。路径 A 保持原口径不变。

# trix_vpt_research_v81 —— 反单触发器换代 + 量仓门（最终口径、移植参照）

## v72 → v81 的完整演进（中间代实验内联，不引用外部章节）

**第一步：诊断 v72 触发器的滞后（数据）**
- 21 笔 v56 反单中，亏损单入场时价格已从近期极值走了 20.7%（中位）、盈利单仅 13.7%
  ——等三线穿越 EMA40 确认，亏损单正好接在动能衰竭段（"中段追单"）；
- 入场前 5 日内出现天量（>2×14日均量）的反转单 5 败 1 胜——V 型顶的巨量在极值处
  当场发生，等穿越时已错过放量信息；
- 盈利单入场时 SAR 平均已先翻 11.1 天——SAR 是更早的反转探测器（系统内已闲置）。

**第二步：触发器前移定型（贴近极值 + 结构破位）**
原型版用固定 10% 阈值，在低波动品种上恒真导致反复触发（ag 回撤 -32.95%，净利 49.45）
→ 改为 ATR 归一化 `距极值 ≤ K×ATR`（K 扫参取 3.0 定稿）。移仓的触发收益上限得到验证
（草稿变体曾达全品种 592.72%），但裸触发回撤过大。

**第三步：确认门的两次失败与一次成功**
- **日内单日量仓门（失败弃用）**：触发当刻看当日实时量/仓——孤立一天噪音过大；
- **提前确认触发器系列（三线排列判据 / EMA5 反穿 EMA20，失败弃用）**：两次实现
  （新状态机/新判据）事件级质量更好（含捕获 2025-06 全商品反转族：jm +59.7 万、
  ps +38.2 万、fg +35.4 万），但单仓模型下"更早更频繁的入场"把仓位时间占掉，
  挤占通道压缩路径大赢单（通道分账 -75 万 ~ -93 万），总账反而变差
  ——**单仓挤占效应三次复现**。结论固化：反单改进方向 = "少而准"（频率控制），
  不做"早而多"（提前确认）；
- **多日综合量仓门（成功定型）**：62 个贴近极值+结构破位事件的描述性分析
  （近 3 日均量/近 14 日均量、持仓同构，截至 T-1）：缩量+减仓 43.5% > 基准 33.9% >
  放量系 25~28.6%。全品种回测：合计 net 559.57%（比 v56 +128.9pct）、
  回撤 109.06%（**低于 v56 的 119.39%**），确认采用。

**第四步：两道否决（记录为边界）**
- 破位强度门（击穿深度 ≥0.25×ATR）：事件级单调有效（0.25~0.5 组 +1.76%/56.2%、
  0.5~1.0 组 +3.96%/83.3%）但集成回测变差——交集版把 fg 的中破位赢单池打空
  （-58pct），单用版又挤占通道路径。不启用（保留为"强反转独立子策略"方向的证据）；
- 反单新鲜度节流（触发资格的时限参数）：如上节，否决。

## v81 最终口径（按代码逐项）

| 项 | v72 | v81 |
|---|---|---|
| 路径 B 触发器 | 三线首穿 EMA40（状态机）+ SAR + CCL 门 | **贴近极值 + 结构破位 + SAR 同向**（见下），无 CCL 条件 |
| 极值过滤 | `cur_can_open_*`（0.5 粗过滤）保留 | 保留，另加**反单专用贴近锚**：`T-1 60日高点 − 当前分钟close ≤ 3×ATR14`（做空）/ `当前分钟close − T-1 60日低点 ≤ 3×ATR14`（做多） |
| 结构破位 | 无 | 做空：`cur_close < T-1 7日低点`；做多：`cur_close > T-1 7日高点` |
| 量仓门 | 无 | **缩量 + 减仓**（默认开，实现见下） |
| 路径 B 止损 | 近 7 日低点−1×tick（多）/ 近 7 日高点+1×tick（空） | 同 v72（继承） |
| 路径 A 与全部出场 | — | 与 v72/v56 完全一致 |

**量仓门实现**：逐交易日收口的总量 deque（分钟成交量求和）与该日**末根分钟 bar** 的
持仓量 deque（新交易日首根先收口上一交易日）；触发时要求两 deque 均 ≥15 天，
否则 fail-open；条件 = `近3日均量 / 近14日均量 ≤ 1.0` 且
`近3日均持仓 / 近14日均持仓 ≤ 1.0`；另有两处零量基线的防御分支。

**退役部件**：`EmaPackCrossStateMachine` 仍实例化并逐日推进，但 v81 触发器不再消费它
（历史保留）；`daily_ccl_type_arr` 仍读取但不参与条件。

# trix_vpt_research_v85：量仓门喂入起点解耦（与 trowel 门状态对称）

## 动机（信号对齐调查的第 2 层修复）

trowel 移植验证发现两侧信号数量不一致。逐层剥离定位到三层差异：
1. 竞价脏 bar 污染（FG 1709 根/其余品种 0 根）——v84 过滤修复，FG 数字 -1.05pct；
2. **量仓门 fail-open 不对称**（本轮 v85 修复）；
3. 同一信号 episode 的触发时点漂移（待第 3 层插桩定位）。

第 2 层的机制：研究侧量仓门 deque 随 exec_df（strict dropna 后）才开始喂入，
exec_df 起步后的前 ~15 个交易日内门处于 fail-open（历史 <15 天放行），
而 trowel 的门从 cache 起点即开始喂入、同一时刻已在正常计算——
同一信号在两侧一门放行一门拦截（FG 2023-11-09 21:30 为典型案例，
运行时 deque 挂钩实证：研究侧 13 条 fail-open，trowel 侧 vol_ratio 1.149 拦截）。

## v85 实现

门的逐日喂入数据改从**完整日线序列**（strict dropna 之前的 daily_signal_df，
逐日 own 值）提取；hybrid 循环前把"早于 exec_df 首个交易日"的天数**预填** deque
（maxlen 20 自动只留最近 20 天），循环内现有收口逻辑不变（避免重复喂入）。
门的可见历史起点与 trowel 对齐，fail-open 窗口消失。

## 补充：T-1 主力重映射的周末空洞修复（2026-11-12，基类 bug fix）

信号对齐调查的第 3 层发现：`use_t1_major` 的 T-1 重映射键 = 交易日序列，
**周末/节假日的凌晨 bar（calendar date 不在键序列中，如周六 07-20 00:18）**
lookup 主力梯队返回 None → 研究引擎的 `cur_major_contract_bar is None → continue`
**跳过整个凌晨段** → 错失该时段触发（sc 07-20 00:18 为首例；trowel 侧 mock 的
`_lookup_trading_date` 有向后容忍故无此问题）。

**修复**：T-1 重映射后按**日历日**逐日填充键空间（交易日 d 与下一交易日之间的
日历日沿用 d 的梯队；末尾交易日之后的日历日沿用最后已知梯队）。
单元验证：首交易日/跨周末/节假日/末端全过。

# trix_vpt_research_v89：反转搏击反向信号可触发反手（第六次"反转路径扩权"否决，留档）

## 动机（信号对齐调查衍生的设计问题，用户提出）

反手权利不对称：通道反向条件在任何持仓下都触发反手，反转搏击反向信号一律忽略。
用户问：通道持仓期间反转结构发出相反信号，是否应该平仓反向开仓？若做，三方向
信号计数能否一致？（计数可加性已另证结构性不可能：三方向是独立回测轨迹。）

## 实现（v89 = v85 + 一格补齐）

反转搏击反向信号作为反手触发器，插在通道反手之后、止损之前（主动翻向指令，
与通道反手同级）；反手止损用**反转路径的结构位口径**（开空=近 7 日高点+1×tick、
开多=近 7 日低点−1×tick，与 ema_condition 直接开仓一致）；open_reason =
`ema_condition_reverse`（通道反手保持空串）；SAR/贴近极值锚/量仓门随条件自动继承；
open_memory 置位与通道反手一致。

# 收益回撤统计（正确口径，v56 / v68 / v72 / v85，2026-11-15）

数据源：`brief-summary-data-{v}.txt`（净利/回撤/笔数/起止，已实现口径）与逐日 MTM 权益曲线（`*equity.html` 内嵌 plotly 二进制序列，风险比率数据源）。只列品种级统计，不做任何汇总；按版本分表（每表 = 六品种 × ALL/LONG/SHORT），方便横向看单个版本。

指标定义与计算公式：

- **年化收益率** = `(期末权益 / 期初权益)^(365.25 / 自然日跨度) − 1`，即总收益率的复合年化；自然日跨度 = 权益曲线首末日期之差（自然日）；
- **夏普比率** = 日收益均值 ÷ 日收益标准差 × √252（无风险利率取 0；日收益由逐日 MTM 权益差分；含空仓期的零收益日）；
- **卡玛比率（Calmar）** = 年化收益率 ÷ |最大回撤|；
- **已知伪影**：sc 的 equity 总收益含最后交易日（07-02）未平仓 MTM，brief 净利 = 07-03 强平已实现值，差 1.42%（ALL）/0.71%（SHORT）——窗口截尾伪影；表内净利统一用 brief 已实现口径，风险比率用 MTM 曲线（受该伪影影响可忽略）。
