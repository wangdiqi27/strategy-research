# trix_vpt_research_v4

使用品种所有合约计算出的指数进行回测。

摒弃 VPT 指标， trix + vpt 指标双重确认，经常性导致趋势信号延迟很多。

该版本使用通道波动率压缩指标，来做趋势突破策略。trix 指标作为判断趋势是否反转的信号指标。


## 多头


### 开仓

1. 量价指标： 昨日价格上涨，成交量比14日平均成交量大 1.5 倍
2. trix指标：trix_hist diff > 0，且 trix_hist > 0，代表整体趋势看多
3. 通道指标:
   - 过去 20 天的最高点
   - 过去 20 天的最低点
   - 通道宽度=最高点 - 最低点
   - 通道压缩率=通道宽度 / daily_atr_20
   - 通道压缩率_20 = 过去 60 天通道压缩率的 20 值
   - 通道波动率是否压缩: 通道压缩率 < 通道压缩率_20，认为波动率已经很低
3. 通道波动率确认压缩至极值

上面两个指标同时满足，允许今日做多


1. 今日开盘60分钟后
2. 今日最新1分钟K线 Close 价格突破通道上沿
3. 今日最新行情是上涨的:与今日开盘价比较

进行开仓

止损: max(通道低点, 入场价 - daily_atr_14 * 2)



### 平仓

1. 止损
2. 至少持仓7天 AND trix 指标反转： trix_hist diff < 0 AND trix_hist < 0，代表整体趋势看空
3. 最后一天可交易日
