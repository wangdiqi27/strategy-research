# trix_vpt_research_v4

使用品种所有合约计算出的指数进行回测。

摒弃 VPT 指标， trix + vpt 指标双重确认，经常性导致趋势信号延迟很多。

该版本使用通道波动率压缩指标，来做趋势突破策略。trix 指标作为判断趋势是否反转的信号指标。


## 多头


### 开仓

1. 量价指标： 昨日价格上涨，成交量比14日平均成交量大 1.5 倍
2. trix指标：trix_hist diff > 0，且 trix_hist > 0，代表整体趋势看多
3. 通道指标:
   - 过去 20 天的最高点
   - 过去 20 天的最低点
   - 通道宽度=最高点 - 最低点
   - 通道压缩率=通道宽度 / daily_atr_20
   - 通道压缩率_20 = 过去 60 天通道压缩率的 20 值
   - 通道波动率是否压缩: 通道压缩率 < 通道压缩率_20，认为波动率已经很低
4. 通道波动率确认压缩至极值
5. TODO: 拐点

上面两个指标同时满足，允许今日做多


1. 今日开盘60分钟后
2. 今日最新1分钟K线 Close 价格突破通道上沿
3. 今日最新行情是上涨的:与今日开盘价比较

进行开仓

止损: max(通道低点, 入场价 - daily_atr_14 * 2)



### 平仓

1. 止损
2. 至少持仓7天 AND trix 指标反转： trix_hist diff < 0 AND trix_hist < 0，代表整体趋势看空
3. 最后一天可交易日

## trix_vpt_research_v10

v10 版本，基于 v9

## 平仓条件调整
1. 修改K线形态反转平仓逻辑
   - 原逻辑是看上一个交易日是否是一根巨型反转K线，如果是，则当日进行平仓
   - 修改后的逻辑是实时判断当日的K线形态，如果满足巨型反转K线条件，立刻平仓

## 结论

缺点：
1. 因为实时计算当日的K线形态时，由于行情并未走完，实体长度比例、上下影线的比例都是失真的。 
   如果行情中有比较多的长上影和长下影线，会导致提前退出趋势行情。这种情况下， 
   不如使用上一根K线形态来判断巨型K线的效果。在 ag、jd、MA 品种中效果比较差。
2. 一般发生巨型K线后，下一根K线很有可能有部分回调，放在第二天再平仓，影响也不是很大。

优点：
1. 如果确实发生了巨型K线反转，且不带回调的情况，这会帮助我们提前退出，减少损失。

分析原因
ag、jd、MA 收益大幅下滑分析：

ag 主要就是因为 2025-11-28 的一次开仓，v9版本吃到了比较大的趋势行情，v10版本因为当日K线形态
判断，2025-12-24 日有一条长下影线，导致日内判断时认为是一条巨型反转K线，但是其实收盘时已经不再是
大的实体K线

jd、MA 与 ag 类似

分析原因：
着重分析 3 倍的情况：
ag : 
1. 2025-11-28 开仓，2025-12-29 日被动态止盈止损，导致一个大的趋势没吃到，收益下降明显

# trix_vpt_research_v13

v13 版本，基于 v9

增加分形指标，识别 HH LH LL HL
- 左侧 bar 数量 L_N,右侧 bar 数量 R_N
- 当 bar.high 大于所有左侧和右侧的 bar.high，则为区间最高点
- 当 bar.low 小于所有左侧和右侧的 bar.low，则为区间最低点
- 识别 HH LH LL HL 结构

## 开仓条件
新增
- 不允许在 LH-LL 时开多单
- 不允许在 HH-HL 时开空单

## 平仓条件
新增
- 多单在识别到 LH-LL 时进行平仓
- 空单在识别到 HH-HL 时进行平仓

## 结论

对交易改善并不明显，当窗口大小选择为 [2, 4] 时，对品种的改善效果并不是一致的。

1. 因为分形指标不像zigzag指标，它的高低点并不是轮替出现的，
2. 而且，只要大于和小于左右两侧就认为是局部的高点和低点，
3. 这些原因导致高低点幅度变化并不大，但是却也被识别为 HH LH LL HL 结构


# trix_vpt_research_v14

v14 版本，基于 v9

增加 zigzag 指标，识别 HH LH LL HL
- 记录最新的高点和低点
- 如果最新的bar.low 与记录的最高点相差一个 threshold，则之前记录的最高点则被确认为最近的最高点 
- 如果最新的bar.high 与记录的最低点相差一个 threshold，则之前记录的最低点则被确认为最近的最低点
- 交替确认最高点和最低点
- threshold = atr * 1.5
- 识别 HH LH LL HL 结构

## 开仓条件
新增
- 不允许在 LH-LL 时开多单
- 不允许在 HH-HL 时开空单

## 平仓条件
新增
- 多单在识别到 LH-LL 时进行平仓
- 空单在识别到 HH-HL 时进行平仓

## 结论

与分形指标的不同点
- 高低点交替出现
- 使用波动率倍数来确认最近的高低点，使结构更明显。
  代价是，确定高低点时，不知道延时了多少根Bar，分形指标可以明确知道延时了窗口大小根 Bar。

对 lc、ag 收益有改进， MA 收益大幅降低

分析 MA 收益下降原因 
1. 主要缺点就是因为 zigzag 指标确认方式带来的:
   - 确认高低点需要反向运行超过一定幅度
   - 当前面还在识别成 LH-LL 时，最新的行情已经开始快速上涨，且不带回调，导致结构一直还是 LH-LL，
     因为不带回调，导致无法确认最新的高点


# trix_vpt_research_v15

v15 版本，基于 v14

主要是为了修改 zigzag 开平仓条件，因为 zigzag 的高低点确认机制，导致根据确认的高低点结构开仓会有问题，该版本主要解决这个问题。


## 开仓条件
新增
- 不允许在 LH-LL，且最新价格小于上一个确认高点时开多单：假设最新价成为未来的确认高点，如果大于上一个高点，则代表结构变化
- 不允许在 HH-HL，且最新价格大于上一个确认低点时开空单：假设最新价成为未来的确认低点，如果低于上一个低点，则代表结构变化

## 平仓条件
新增
- 多单在识别到 LH-LL，且最新价小于上一个确认高点时进行平仓
- 空单在识别到 HH-HL，且最新价大于上一个确认低点时进行平仓

## 结论

对某些zigzag极端情况有改善作用

# 详细描述

## 指标
1. trix指标：trix_hist diff > 0，且 trix_hist > 0，代表整体趋势看多
2. 通道指标:
   - 过去 20 天的最高点
   - 过去 20 天的最低点
   - 通道宽度=最高点 - 最低点
   - 通道压缩率=通道宽度 / daily_atr_20
   - 通道压缩率_20 = 过去 60 天通道压缩率的 20 值
   - 通道波动率是否压缩: 通道压缩率 < 通道压缩率_20，认为波动率已经很低 
3. 跳空判断
   - 当日开盘价跳空是否大于 1% 上一日收盘价
   - 上一日K线是否是跳空行情
4. K线形态判断
   - K线区间 High - Low
   - K线实体 abs(Close - Open)
   - K线方向，上涨 1，下跌 -1，不变 0
   - K线上影线比例
   - K线下影线比例
   - K线实体比例
   - 是否是巨型K线：K线区间大于过去60天的 90 分位值
5. trix 正负连续天数判断
   - 统计 trix 持续大于 0 的天数
   - 统计 trix 持续小于 0 的天数 
6. zigzag 结构指标识别 HH LH LL HL
   - 记录最新的高点和低点
   - 如果最新的bar.low 与记录的最高点相差一个 threshold，则之前记录的最高点则被确认为最近的最高点 
   - 如果最新的bar.high 与记录的最低点相差一个 threshold，则之前记录的最低点则被确认为最近的最低点
   - 交替确认最高点和最低点
   - threshold = atr * 1.5
   - 识别 HH LH LL HL 结构


## 多头开仓
1. 当前处于通道压缩
2. 最新1分钟收盘价大于通道高点 + 0.1 * daily_atr_14
3. 开盘30分钟后
4. 最新1分钟数据计算，当天是一根阳线
5. 不允许在 LH-LL，且最新价格小于上一个确认高点时开多单：假设最新价成为未来的确认高点，如果大于上一个高点，则代表结构变化


止损设置:
stop_loss = max(通道低点，开仓价 - daily_atr_14 * 2)

动态止盈止损设置
adjust_stop_loss = max(stop_loss, 持仓后的高点 * 0.8)   TODO: 最近的高点

## 多头平仓
1. 达到止损条件
2. 达到动态止盈止损条件
3. 当日开盘跳空反转达到 1%
4. 上一日是一个确认的跳空反转K线
5. 上一日是一个巨型反转K线
6. trix 反转，持仓大于 7 天，不处于通道压缩期，trix 小于0持续大于等于5天
7. 最后可交易日


## 空头开仓

1. 当前处于通道压缩
2. 最新1分钟收盘价大于通道低点 - 0.1 * daily_atr_14
3. 开盘30分钟后
4. 最新1分钟数据计算，当天是一根阴线
5. 不允许在 HH-HL，且最新价格大于上一个确认低点时开空单：假设最新价成为未来的确认低点，如果低于上一个低点，则代表结构变化

止损设置:
stop_loss = min(通道高点，开仓价 + daily_atr_14 * 2)

动态止盈止损设置
adjust_stop_loss = min(stop_loss, 持仓后的低点 * 1.2)

## 空头平仓
1. 达到止损条件
2. 达到动态止盈止损条件
3. 当日开盘跳空反转达到 1%
4. 上一日是一个确认的跳空反转K线
5. 上一日是一个巨型反转K线
6. trix 反转，持仓大于 7 天，不处于通道压缩期，trix 大于0持续大于等于5天
7. 最后可交易日

## 结论

lc收益率下滑，
FG、jd、MA 品种收益略增加，
ag 变化不大

## 新增指标

1. EMA40 状态统计
   - `ema40_above_days` / `ema40_below_days`：收盘价处于 EMA40 上方/下方的连续天数，离开该状态后归零

  新鲜趋势环境下的确认破位不同

   且 EMA5 未反向穿越 EMA20 时，排列天数**冻结**（不累加不清零，"认为是连续的"），
   恢复排列后 run 从冻结值继续累加；持续 >= M 天则连续认定失败，run 与锚点清零重新积累
2. 锚点 = 环境（多头环境 = e5>e20）内**第一次**形成多头排列那天的价格；空头环境同理
3. 触发 = EMA5 反向穿越 EMA20：
   - 多头环境 EMA5 下穿 EMA20 → 做空候选；空头环境 EMA5 上穿 EMA20 → 做多候选
   - 触发日综合验证幅度 R（`ema_pack_min_price_change_pct`，除数为锚点价，分方向符号）：
     做空要求 (穿越价 - 锚点)/锚点 > +R；做多要求 < -R（v45 当前默认 0.0 = 启用拦截）
   - 破位即环境终结，被幅度门槛压制的信号不再重试（新一轮环境重新积累）
4. 结算顺序：触发判定（锚点=截至昨日）→ 幅度门槛 → 环境推进/清空；环境重进时 consumed 复位

实现注意：
1. 所有状态布尔值在存储前用 `bool()` 强转（历史 bug：numpy.bool_ 与 `is True`/`is False`

# trix_vpt_research_v54

v54 版本，基于 v53

## 设计意图

在 v53 的 SAR 趋势过滤（入场）之上，新增**SAR 反转即平仓**的退出逻辑：

- 多头持仓：若 T-1 口径 SAR 趋势翻为下跌（`daily_sar_trend == -1`）→ 平多
- 空头持仓：若 T-1 口径 SAR 趋势翻为上涨（`daily_sar_trend == +1`）→ 平空
- "立刻"的落地方式：反转次一交易日的盘中第一时间离场（日线口径下能观察到的最早时点）

## 实现

1. 多头平仓链、空头平仓链各插入一条 elif：
   `daily_sar_trend_arr[i] == -1 / == 1` → `close_reason = "SAR 反转平仓"`
2. 优先级：置于 反手开仓（channel 反向条件）与 止损、动态止盈止损 **之后**，
   开盘跳空反转 **之前**——硬性风控（止损）与反向确认（反手）优先于趋势退出，
   SAR 反转先于其余较钝的信号（跳空反转、巨K、trix）
3. T-1 口径说明：当日盘中只能观察到"昨日收盘后"的 SAR 状态，因此反转平仓
   最早发生在反转次一交易日（与全系统日线指标口径一致，无未来数据）

## 验证（FG，单品种口径）

| | v53（SAR 入场过滤） | v54（+ SAR 反转平仓） |
|---|---|---|
| ALL 净利润 | 52.64% | 12.93% |
| ALL 最大回撤 | -20.90% | -17.43% |
| ALL 交易次数 | 13 | 17 |
| LONG 净利润 | -11.20% | -7.21% |
| LONG 最大回撤 | -21.15% | -20.43% |
| SHORT 净利润 | 72.17% | 21.64% |
| SHORT 最大回撤 | -9.40% | -8.65% |

v54 中 17 笔成交有 13 笔由 "SAR 反转平仓" 离场（合计 +159,236），行为特征：

- **LONG 侧改善**（亏损收窄 4 个点）：SAR 反转把 v53 中等待"止损/开盘跳空反转"
  才离场的多单提前释放（如 2025-09-15 多单 v53 止损 -106,318 → v54 早离场 -13,818）
- **SHORT 侧严重受损**（ALL 收益 52.64% → 12.93% 的降幅主要来自这里）：SAR 震荡期反复
  反转，把趋势单截断成多段小盈/小亏，且回补入场形成额外换手——
  2025-04-17 空单 v53 持有至 trix 反转 +163,900 → v54 于 5/21 提前 +100,534 离场；
  2025-10-21 空单 v53 trix 反转平仓 +95,356 → v54 反转期初段离场变 -27,610；
  2026-03-31 FG609 空单 v53 一笔 +142,680 → v54 拆成三笔（+53,958 / -54,398 / -31,436）
- 本质冲突：本策略是"重仓死扛趋势"型（动态止盈 0.8/1.2 阈值很宽），
  SAR 反转平仓与之竞争离场权，等于把超过一半的持仓时间交给一个高频翻转的指标

## 结论

FG 冒烟负向：ALL 收益 -39.71pct、SHORT -50.53pct，仅 LONG 侧小幅改善；
回撤虽收窄（-17.43% vs -20.90%），但收益/回撤比大幅恶化。
与 v53 的"入场过滤放在下一版本观察相比"，SAR 反转平仓作为独立退出
与现有死扛趋势的退出链冲突明显。可考虑的方向：仅对 LONG 路径启用
（LONG 侧是正贡献）、或对 SAR 反转平仓附加确认缓冲（如连续 N 日反转才离场）。

# trix_vpt_research_v67

v67 版本，基于 v56

## 止损重构：近期高低点 ± N tick（与入场价解耦）

v56 的止损与入场价耦合（入场价 ± 2×ATR，压缩突破路径再与通道边 max/min 取界），
"止损跟着入场点走"缺少结构逻辑。v67 将开仓止损整体改为结构位：

- 做多：`stop_loss = stop_ref_low - N * tick`，其中 `stop_ref_low = low.rolling(stop_lookback_days).min()`
- 做空：`stop_loss = stop_ref_high + N * tick`，其中 `stop_ref_high = high.rolling(stop_lookback_days).max()`
- `N = stop_loss_ticks`（默认 1），`stop_lookback_days`（默认 7，即近一周的高低点）
- 参考高低点取 **T-1 收盘口径**（执行层 shift(1)，与其它日线指标一致，无未来数据）
- 两条开仓路径（通道压缩 / 均线束）**共用同一止损口径**（不再有 max/min 与 ATR 混合界）；
  反向开仓的止损同口径
- `stop_loss_multiplier` 参数移除（v67 中不再与 ATR 挂钩）；止盈保持 3×ATR 不变；
  动态止盈止损（持仓后高低点回撤 20%）保持不变

## 参数

- `stop_loss_ticks = 1`（N 个 tick；不同品种 tick 大小不同，实际距离随品种而异）
- `stop_lookback_days = 7`

## 实验动机：jm 的 -31.34% 最大回撤解剖

v56 中 jm 的最大回撤窗口：**2025-07-25（权益峰值 2,585,211）→ 2026-04-10（谷底 1,775,091），
-31.34%，持续 8.5 个月**。解剖（逐笔 + 日权益曲线）：

   回撤窗口内四笔连亏（-230,440 / -131,161 / -132,512 / -210,627 ≈ **-705k ≈ -28%**），
   若仓位停留在 1M 等级，同样四笔仅约 -12%。
2. **品种波动率同步放大**：jm 从 1625 → 852 → 1259（-47%/+48%），2025-2026 的
   日 ATR/价格比 3~5%（前期 1~2%）。100% 名义仓位下敞口波动随品种波动一起放大。
3. **市场结构切换**：四笔连亏全部在 2025-12 ~ 2026-04——焦煤从单边崩塌转入剧烈反弹震荡，

## 实验内容：波动率目标化仓位上限（全品种统一规则）

```
lots_by_notional = cash // (price * multiplier * margin_rate)        # v56 原口径（不变）
lots_by_vol      = equity * risk_per_atr / (daily_atr_14 * multiplier)  # 1 ATR 逆波动 = risk_per_atr * 权益
volume           = min(两者)
```

- `risk_per_atr = 0.025`（1 ATR 逆向波动 ≤ 2.5% 权益）；六个开仓点（初始/移仓/反向）全部生效
- **统一规则、对所有品种所有时间生效，无 jm 特判，不构成过拟合**；
- 低波动状态（ATR/价格 < 2.5%）时上限不生效——多数品种多数时间行为与 v56 完全一致，
  "不影响其他品种"由构造保证，并以全品种回测实证（见下表）；
- `close_position` 的 volume=0（全平语义）保持不变；`stop_loss_multiplier` 移除；
  信号、SAR、止损口径与 v56 完全一致，只动仓位。

jm 的四连败后的反弹修复单同样被节流（46.11%，比 v56 少 31.4pct），回撤却只改善 6pct（-25.27 vs -31.34）。
节流阀在"亏损后减仓"与"错过修复行情"之间两头不讨好。

## v67/v69/v70 三组风控实验总结论

1. **jm 的 -31% 回撤是"复利满仓 × 高波动 × 震荡期连亏"的内生结果**，不是策略缺陷：
   风险调整后 jm 的收益/回撤比 2.47，与组合均值（~2.9）差距不大；
   其 +77.5% 的高收益正是这笔回撤的对价。
2. **三个统一减仓规则都无法做到"只降 jm 回撤、不影响其他品种"**：
   - v67（SAR/止损重构）：全品种 -13.25pct，FG 专用变体可行；
   - v69（波动率上限 2.5%）：回撤 6/6 改善但砍掉趋势复利收益（lc -27.64），合计 -73.19pct；
     更紧的上限只会更差，理论上可扫 risk_per_atr=4~5% 的松口径，但改善空间有限；
   - v70（权益回撤节流 -10%×0.5）：合计 -130pct，节流时机两头不讨好，最差。
3. **本质矛盾**：本策略的收益机制就是"满仓复利吃大趋势"，任何在亏损段降杠杆的统一规则
   都会同时削弱其他品种的同构盈利段。策略层面的减仓规则无法满足"不影响其他品种"的约束。
4. **落地建议**：
   - 策略层保持 v56 默认（不改）；
   - 若部署层面对 jm 单品种 -31% 回撤有顾虑，在**组合资金分配层**下调 jm 的名义权重
     （组合构建问题，不影响其他品种的策略行为，也不触碰策略代码）；
   - v67（FG 专用）/v69/v70 三个实验档案与参数全部保留，后续若 jm 波动结构变化可复查。

  v76-b 的 fg 增益（133.50 vs v68 69.35）主要来自浅/中破位的缩量减仓单，被强度门清掉；
- v80-b 反单路径本身极好（18 笔 +849,998、61% 胜率，含 fg 2025-06 +370,062 / jm +214,641），
  但通道路径再次被挤占（第三次复现），总账不及 v76-b；
- v80-b 的亏损面：sc 四笔"开盘跳空反转"平仓的 -15.6k/-36k/-60.2k/-63.2k（sc 反单失效品种结论再加强）。

## 结论（最终形态定格）

1. **v76-b 仍是移植候选与全系列最优**（559.57 / 109.06 / 5.13）：其本质是
   "贴近极值 + 结构破位 + 缩量减仓 + 结构位小止损"；
2. 强度门信号成立但加门后不改善集成系统——v76-b 的 fg 赢单来自中等破位而非强破位；
3. "强反转单独成军"（v80-b 的 18 笔 85 万）单路径质量全系列最高，但单仓模型下无法收割——
   归档为**双仓/并行子策略方向的证据**（与 v77/v78 结论一致），
   若未来做双仓架构，v80-b 口径（仅强度门）是反单子策略的首选参数。
